~ Problem Statement :-

Managing daily expenses manually can be difficult because it is easy to forget or lose track of where money is being spent. This project provides a simple Python program to record and manage personal expenses in one place.

~ Scope:- 

The project is designed for managing personal day-to-day expenses. It can be used to record expenses, view saved expenses, calculate total spending, delete expenses, and check spending by category.

~ Target User:-

The main target users of this project are people who want a simple way to record and manage their personal expenses. It can also be useful for students who want to keep track of their daily spendings.

~ High-Level Feature:- 

1. Add a new expense with date, description, category, and amount.
2. View all saved expenses.
3. Calculate the total amount of expenses.
4. Delete an existing expense.
5. View a category-wise summary of expenses.
6. Store expense records in a CSV file.
7. Validate the amount entered by the user.
