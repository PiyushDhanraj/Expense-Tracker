"PERSONAL EXPENSE TRACKER"

~ About the project :-

This is a Python program for keeping track of personal expenses. It allows the user to add expenses and save them in a CSV file. The user can also view expenses, calculate the total amount, delete an expense, and see the expenses according to their category.

~ Features :-

1. Add expense
2. View Expense
3. Calculate total expense
4. Delete expense
5. Category Summary
6. Save expense in a CSV file

~ Technology Used :-

1. Python
2. CSV file handling
3. Dictionary
4. Lists
5. Loops
6. Exception handling

~ How to run :-

1. Open the Expense-Tracker folder in VS Code.
2. Open the terminal.
3. Run: python main.py
4. The menu will appear.
